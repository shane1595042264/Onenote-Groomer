# DocFlow AI - Demo Script (2.5 Minutes)

## Opening Hook (15 seconds)
"Hi everyone! Today I'm excited to show you **DocFlow AI** - an intelligent document processing tool that transforms any document into structured Excel data using local AI. What makes this special? Everything happens on your device - no cloud, no data sharing, complete privacy."

## Problem Statement (20 seconds)
"We've all been there - you have documents full of valuable data, but it's trapped in unstructured formats. Converting OneNote files, PDFs, or Word docs into Excel manually is time-consuming and error-prone. That's where DocFlow AI comes in."

## Live Demo - Core Features (90 seconds)

### Feature 1: Drag & Drop Simplicity (30 seconds)
"Let me show you how simple this is. I'll drag a OneNote file here... 
*[Drag file to app]*
Notice how the interface is clean and intuitive. The app immediately recognizes the file type and prepares for processing."

### Feature 2: AI-Powered Extraction (40 seconds)
"Now here's the magic - our AI prompt system. I can choose from presets like 'Meeting Notes', 'Sales Data', or create custom prompts.
*[Show preset buttons]*
Let me select 'Meeting Notes'... and you can see it automatically configures to extract attendees, action items, decisions, and deadlines.
*[Click process]*
Watch as the local AI processes this in real-time - no internet required, everything stays private on my machine."

### Feature 3: Smart Excel Output (20 seconds)
"And here's our result - a perfectly structured Excel file with organized data, proper headers, and clean formatting. The AI understood the context and extracted exactly what we needed."

## Technical Excellence (30 seconds)
"From a technical standpoint, this showcases several advanced concepts:
- **Local AI integration** with Ollama for privacy
- **Flutter desktop development** with Material Design 3
- **Smart file processing** with conflict resolution
- **MSIX packaging** ready for Microsoft Store deployment"

## Value Proposition (15 seconds)
"DocFlow AI saves hours of manual work, ensures data privacy with local processing, and provides professional-grade results. It's perfect for businesses, researchers, or anyone dealing with document data extraction."

## Closing (10 seconds)
"Thank you! DocFlow AI - where intelligent document processing meets complete privacy. Any questions?"

---

## Demo Tips:
- Have sample files ready (OneNote, Word, PDF)
- Show both preset and custom prompts
- Emphasize the "local processing" aspect
- Keep the demo moving - don't wait for long processing
- Have backup screenshots if live demo fails
- End with the generated Excel file open
